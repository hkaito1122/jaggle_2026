# 10年定着予測 - 探索的データ分析レポート

**プロジェクト**: HR Analytics 10年定着予測  
**分析日**: 2026年8月5日  
**分析者**: Data Science Team

---

## エグゼクティブサマリー

本レポートは、社員の入社後2年間（0-23ヶ月）のデータから、入社10年後（120ヶ月時点）の在籍を予測する機械学習モデル構築に向けた探索的データ分析の結果をまとめたものです。

### 主要な発見

* **定着率**: 56.47%（1,559名が定着、1,202名が退職）と比較的バランスの取れたデータ
* **強い予測因子**: 入社時年齢、前職経験月数、初任給が目的変数と正の相関（0.13-0.15）
* **時系列パターン**: 残業時間、研修時間、360度評価スコアに定着・退職の明確な違い
* **欠損値**: 前職職種（73%）、顧客満足度評価（65%）、担当プロジェクト数（48%）に高い欠損率

## 2. 欠損値分析

### 2.1 属性データの欠損値

| カラム名 | 欠損件数 | 欠損率 |
|---------|---------|--------|
| 前職職種 | 2,025件 | 73.34% |

**考察**:  
前職職種の高い欠損率（73%）は、新卒入社者が多いことを示唆しています。この変数は、欠損値自体を「新卒」を示す情報として扱うことができます。

### 2.2 月次データの欠損値

| カラム名 | 欠損件数 | 欠損率 |
|---------|---------|--------|
| 顧客満足度評価 | 42,969件 | 65.35% |
| 担当プロジェクト数 | 31,228件 | 47.49% |
| 360度評価_親和度 | 13,593件 | 20.67% |
| 360度評価_信頼度 | 13,593件 | 20.67% |
| 360度評価_主体度 | 13,593件 | 20.67% |
| 360度評価_学習度 | 13,593件 | 20.67% |
| 360度評価_共有貢献度 | 13,593件 | 20.67% |
| 360度評価者数 | 13,593件 | 20.67% |

**考察**:

1. **顧客満足度評価（65%欠損）**: 顧客接点のない職種（バックオフィス、開発等）が存在
2. **担当プロジェクト数（48%欠損）**: プロジェクト制でない業務形態の社員が存在
3. **360度評価（21%欠損）**: 評価実施タイミングの制約（入社直後は評価なし等）

**対応方針**:
* 欠損値を「該当なし」カテゴリとして扱う
* 欠損フラグを追加特徴量として作成
* 時系列での欠損パターン（いつから評価が始まるか等）を特徴化

## 5. 月次データの時系列分析

### 5.1 主要な時系列パターン

EDAノートブックで分析された以下の変数で、定着・退職社員の明確な違いが観察されました：

#### 残業時間
* **退職社員**: 入社直後から残業時間が多く、時間経過とともに増加傾向
* **定着社員**: 残業時間が比較的少なく、安定的に推移
* **相関**: 入社月の残業時間と目的変数で負の相関（-0.16）

#### 研修時間
* **退職社員**: 研修時間が少ない
* **定着社員**: 研修時間が多く、継続的に研修を受講
* **相関**: 入社月の研修時間と目的変数で負の相関（-0.15）→データ確認が必要

#### 上司との面談実施回数
* **定着社員**: 面談回数が多い傾向
* **退職社員**: 面談回数が少ない傾向

#### 360度評価スコア
* **定着社員**: すべての評価項目（親和度、信頼度、主体度、学習度、共有貢献度）で高いスコア
* **退職社員**: 評価スコアが低い傾向
* 評価は入社後数ヶ月経過してから実施されるため、時系列での変化パターンが重要

### 5.2 月末在籍状態の推移

* **在籍**: 経過月数とともに減少
* **休職**: わずかに存在
* **退職**: 経過月数とともに増加

退職タイミングは入社後2年間（0-23ヶ月）の間に徐々に発生しており、特定の時期への集中は見られませんでした。

## 7. 主要な発見事項のまとめ

### 7.1 定着に影響する要因

**正の影響（定着を促進）**:
1. 高い入社時年齢
2. 長い前職経験
3. 高い初任給
4. 高い360度評価スコア
5. 多い上司との面談回数

**負の影響（離職リスクを高める）**:
1. 多い残業時間（特に入社直後）
2. 少ない研修時間（ただし解釈に注意）
3. 低い360度評価スコア

### 7.2 データ品質に関する知見

* **欠損値パターン**: 職種や業務形態による構造的な欠損が多い
* **時系列の一貫性**: 月次データは連続的で、異常値は少ない
* **テキストデータ**: 3つのテキストフィールド（入社時メモ、フィードバック）が未活用

## 9. モデリング戦略

### 9.1 ベースラインモデル

```python
# Step 1: シンプルな特徴量でベースライン構築

1. ロジスティック回帰
   - 基本的な数値特徴量のみ使用
   - 目標: Log Loss < 0.68（全員に0.5647を予測した場合）

2. 勾配ブースティング（LightGBM/XGBoost）
   - 基本特徴量 + カテゴリカル変数
   - 目標: Log Loss < 0.60
```

### 9.2 特徴量エンジニアリング後のモデル

```python
# Step 2: 全特徴量を使用したモデル

1. LightGBM
   - 全特徴量（月次集約 + カテゴリカル + テキスト）
   - ハイパーパラメータチューニング（Optuna等）

2. CatBoost
   - カテゴリカル変数の自動処理
   - 順序エンコーディングの活用

3. ニューラルネットワーク
   - 数値・カテゴリカル・テキスト埋め込みの統合
   - Entity Embedding for categorical variables
```

### 9.3 アンサンブル


## 15. 時系列特徴量のトレンド分析

### 15.1 線形回帰による傾き分析

各社員の0-23ヶ月間の時系列データに対して線形回帰を適用し、月あたりの変化率（傾き）を算出しました。

| 変数 | 退職者の傾き | 定着者の傾き | 差分 |
|------|-------------|-------------|------|

| 月例給与_円 | +403.46円 | +459.66円 | **+56.20円** |

**主な発見**:

#### 残業時間
* 両者とも増加傾向だが、**退職者の方が増加率が高い**（月+0.24時間 vs +0.14時間）
* 退職者は入社直後から残業が多く、さらに加速する傾向

#### 研修時間
* 両者とも減少傾向（入社初期は研修が多く、徐々に減少）
* 退職者の方が減少幅が大きい（月-1.78時間 vs -1.48時間）

#### 上司との面談回数
* わずかな減少傾向（差は微小）

* 両者とも昇給しているが、**定着者の方が昇給率が高い**（月+460円 vs +403円）

* 定着者の方が評価され、給与に反映されている可能性

**考察**:
* **残業時間の増加トレンド**は強力な離職予測因子
  - 初期の高残業に加え、さらに増加する「悪循環」
  - ワークライフバランスの悪化が離職につながる
* **研修機会の減少**も注意が必要
  - 育成投資の継続が定着を促進
  - OJTと研修のバランスが重要
* **給与上昇率**は評価・成長の代理指標
  - 定着者の方がパフォーマンスが高い可能性
  - または組織が定着者により報いている

**特徴量エンジニアリングへの示唆**:
* 各数値変数の「傾き」を特徴量化（線形回帰のslope）
* 初期値vs最終値の差分・比率も有効
* 急激な変化（変化点検出）も追加検討
