10年定着予測 - 探索的データ分析レポート

プロジェクト: HR Analytics 10年定着予測

分析日: 2026年8月5日

分析者: Data Science Team

エグゼクティブサマリー

本レポートは、社員の入社後2年間（0-23ヶ月）のデータから、入社10年後（120ヶ月時点）の在籍を予測する機械学習モデル構築に向けた探索的データ分析の結果をまとめたものです。

主要な発見

  • 定着率: 56.47%（1,559名が定着、1,202名が退職）と比較的バランスの取れたデータ
  • 強い予測因子: 入社時年齢、前職経験月数、初任給が目的変数と正の相関（0.13-0.15）
  • 時系列パターン: 残業時間、研修時間、360度評価スコアに定着・退職の明確な違い
  • 欠損値: 前職職種（73%）、顧客満足度評価（65%）、担当プロジェクト数（48%）に高い欠損率

3. 目的変数の分析

3.1 定着率

定着（1）: 1,559名 (56.47%)

退職（0）: 1,202名 (43.53%)

定着率: 0.5647 (56.47%)

3.2 考察

  • クラスバランス: 比較的バランスが良い（56:44）ため、特別なクラス不均衡対策は不要
  • ベースライン: 全員に定着率0.5647を予測した場合のLog Lossは約0.68
  • 評価指標: Log Lossは確率の精度を重視するため、予測確率の校正（calibration）が重要

5. 月次データの時系列分析

5.1 主要な時系列パターン

残業時間

  • 退職社員: 入社直後から残業時間が多く、時間経過とともに増加傾向
  • 定着社員: 残業時間が比較的少なく、安定的に推移
  • 相関: 入社月の残業時間と目的変数で負の相関（-0.16）

360度評価スコア

  • 定着社員: すべての評価項目で高いスコア
  • 退職社員: 評価スコアが低い傾向
  • 評価は入社後数ヶ月経過してから実施されるため、時系列での変化パターンが重要

6. 特徴量エンジニアリングの提案

6.1 月次データの集約特徴量

統計量ベース

各数値変数について、0-23ヶ月の期間で以下を計算:

  • 基本統計量: 平均、標準偏差、最小値、最大値、中央値、変動係数
  • 時期別統計量: 初期・中期・後期の平均、差分
  • トレンド特徴量: 線形回帰の傾き、最終値と初期値の差・比率

対象変数: 残業時間、有給取得日数、研修時間、面談回数、360度評価、顧客満足度、担当プロジェクト数、月例給与

6.2 カテゴリカル変数の処理

  • One-Hot Encoding: 入社区分、性別、最終学歴、専攻分野、採用経路、初期職種、初期勤務地、初期役割
  • Target Encoding: 初期部署ID、専攻分野、前職職種（CV内でリーク防止）
  • 順序エンコーディング: 初期等級、最終学歴

6.3 テキストデータの特徴抽出

  • TF-IDF特徴量: 入社時メモ、上司・同僚からのフィードバック（max_features: 50-100、ngram_range: (1,2)）
  • テキスト統計量: 文字数、単語数、文数、平均単語長、感情分析
  • 埋め込み: 日本語BERT等で埋め込みを取得し、PCA/UMAPで圧縮

6.4 月次データのカテゴリカル変数

  • 変化パターン: 部署異動回数、職種変更回数、役割変更・昇進フラグ、等級上昇回数、勤務地変更回数、上司変更回数
  • 在籍状態: 休職経験フラグ、休職月数、在籍継続月数

6.5 交互作用特徴量

  • 年齢 × 前職経験月数
  • 初任給 × 初期等級
  • 残業時間 × 研修時間
  • 360度評価の合計/平均
  • 入社区分 × 前職経験月数

6.6 欠損値を活用した特徴量

  • 前職職種欠損フラグ（= 新卒フラグ）
  • 360度評価欠損率（0-23ヶ月で何%の月が欠損か）
  • 顧客満足度評価欠損率
  • 担当プロジェクト数欠損率

7. モデリング戦略

7.1 ベースラインモデル

  1. ロジスティック回帰: 基本的な数値特徴量のみ使用、目標 Log Loss < 0.68
  2. 勾配ブースティング: LightGBM/XGBoost、目標 Log Loss < 0.60

7.2 特徴量エンジニアリング後のモデル

  1. LightGBM: 全特徴量 + ハイパーパラメータチューニング
  2. CatBoost: カテゴリカル変数の自動処理
  3. ニューラルネットワーク: Entity Embedding、数値・カテゴリカル・テキスト埋め込みの統合

7.3 アンサンブル

  • スタッキング: Level 1（LightGBM, XGBoost, CatBoost, NN）、Level 2（ロジスティック回帰 or LightGBM）
  • ブレンディング: 各モデルの予測確率の加重平均

7.4 クロスバリデーション戦略

  • StratifiedKFold (5-fold): 目的変数の比率を維持
  • TimeSeriesSplit: 入社日順にソートしてから分割（オプション）

7.5 確率キャリブレーション

Log Loss最適化のため、予測確率の校正が重要です：

  • Platt Scaling（ロジスティック回帰）
  • Isotonic Regression
  • Beta Calibration

8. 次のステップ

8.1 優先度: 高

  1. 特徴量エンジニアリングの実装: 月次データの集約特徴量、カテゴリカル変数のエンコーディング、欠損値処理
  2. ベースラインモデルの構築: ロジスティック回帰、LightGBM/XGBoost
  3. 特徴量重要度の分析: 有効な特徴量の特定と不要な特徴量の削除

8.2 優先度: 中

  1. テキストデータの活用: TF-IDF特徴量、感情分析
  2. 月次カテゴリカル変数: 部署異動、職種変更等のパターン特徴量
  3. ハイパーパラメータチューニング: Optuna/Hyperoptを使った自動最適化

8.3 優先度: 低（応用）

  1. employee_monthly_train_full.csvの活用: 24ヶ月以降のデータから退職パターンを分析（直接特徴量には使用しない）
  2. 高度なモデリング: ニューラルネットワーク、時系列モデル（LSTM/Transformer）
  3. モデルの解釈性: SHAP値、Partial Dependence Plot

リスクと注意事項

データリークのリスク

  • employee_monthly_train_full.csvの24ヶ月以降のデータは特徴量として直接使用しない
  • Target Encodingはクロスバリデーション内で適切に行う

過学習のリスク

  • 特徴量が多すぎると過学習しやすい
  • 対策: 特徴量選択、正則化、Early Stopping

時系列の偏り

  • Trainは2011-2014年、Testは2014-2017年と時期が異なる
  • 対策: 時系列CVでバリデーション戦略を検証

結論

本EDAにより、10年定着予測の機械学習モデル構築に向けた基盤が整いました。

主要な知見

  1. 定着率は56%と比較的バランスが良く、クラス不均衡対策は不要
  2. 入社時年齢、前職経験、初任給が定着と正の相関
  3. 残業時間、360度評価など月次データの時系列パターンに明確な差
  4. 欠損値は職種・業務形態による構造的なものが多く、情報として活用可能
