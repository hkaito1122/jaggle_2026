# 課題内容

## 概要

入社した社員が能力を十分に発揮し、長く活躍し続けられるかどうかは入社時点では容易には分かりません。もし入社後まもない時期のデータから、将来の定着に関する傾向や、つまづきのリスクを早期に見立てることができれば、一人ひとりの特性に合わせた育成・配置・フォローアップといった定着支援の打ち手につなげることができます。

本コンテストでは、ある企業の社員について、入社直後（入社後2年間）の属性・行動データをもとに、**入社から10年（120か月）が経過した時点でその社員が在籍しているかを予測する**モデルを構築します。

予測の手掛かりとして使えるのは、テストデータでも観測できる **入社後0〜23か月（最初の2年間）** のデータに限られます。24か月目以降のデータは与えられないため、「最初の2年間の姿」から「10年後の在籍」を当てにいくことになります。

## データ概要

データは「社員属性データ（社員1名＝1行）」と「社員月次データ（社員1名×1か月＝1行）」の2種類で構成され、いずれも `社員ID` で結び付きます。月次データを社員1名につき1行へ集約し、属性データと結合して1つの学習テーブルを作るのが基本的な進め方です。

## 評価方法

### 評価指標：Log Loss（対数損失）

提出された「120か月時点の在籍確率」を、Log Loss（対数損失）で評価します。値が小さいほど良い評価です。

LogLoss = -1/N × Σ[yi × log(pi) + (1 - yi) × log(1 - pi)]


**記号の説明：**
* N：評価対象の社員数
* yi：社員 i の正解ラベル（1＝定着、0＝退職）
* pi：社員 i に対して提出した在籍確率（0 < pi < 1）

Log Loss は、正解が 1 の社員には高い確率を、正解が 0 の社員には低い確率を付けられたかを測ります。自信を持って外した予測（例：正解が 0 の社員に 0.99 を付ける）には大きなペナルティがかかるため、**確率の当てはまり**が重要になります。

### 参考（ベースライン）

特徴量を使わず、全員に一律の定着率（trainデータの平均値=約 0.5647）を予測した場合、Log Loss は約 0.68 です。これを下回れるかどうかが、特徴量やモデルが有効かどうかの目安になります。
