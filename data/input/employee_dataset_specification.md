| --- | --- | --- | --- |

## employee_monthly_train.csv と employee_monthly_train_full.csv の違い

2つのファイルは対象社員と列構成が同じで、観測期間が異なります。

| 項目 | employee_monthly_train.csv | employee_monthly_train_full.csv |
| --- | --- | --- |
| 対象 | 学習用社員 2,761名 | 学習用社員 2,761名 |
| 観測期間 | 入社後 0〜23か月（最初の2年間） | 入社後 0〜119か月（最長10年間） |
| 行数 | 65,754行 | 257,509行 |
| 主な用途 | モデルの学習特徴量の作成 | 長期的な変化や離職までの経過の分析、特徴量設計の仮説づくり |
| Testとの条件 | Testと同じく0〜23か月 | Testには24か月目以降が存在しない |

`employee_monthly_train.csv` は、`employee_monthly_train_full.csv` のうち 経過月数 が0〜23の行と完全に一致します。退職した社員については退職月までの記録となるため、必ずしも全社員に24行または120行があるわけではありません。

**重要**：モデルが予測時に利用できるのは、Testでも観測できる0〜23か月の情報だけです。`employee_monthly_train_full.csv` の24〜119か月目には予測時点より後の情報が含まれるため、そのまま学習特徴量に使用するとデータリークになります。長期データは、離職に至る推移の分析や、「最初の2年間から作れる特徴量」のアイデアを考えるために利用してください。

## 社員属性データ（employee_persona_*.csv）

社員1名につき1行の、入社時点の属性情報です。文章（自然言語）の列も含まれます。

| 列名 | 型（推奨） | 説明 |
| --- | --- | --- |
| 社員ID | 文字列（ID） | 社員を一意に識別するID（例：E000002）。全ファイル共通の結合キー |
| 入社日 | 日付 | 入社日。Trainは2011-04〜2014-03、Testは2014-04〜2017-03 |
| 入社区分 | カテゴリ | 新卒 / 中途 |
| 入社時年齢 | 整数 | 入社時点の年齢 |
| 最終学歴 | カテゴリ | 高校卒 / 専門学校卒 / 短大・高専卒 / 大学卒 / 大学院卒 |
| 専攻分野 | カテゴリ | 人文・教養 / 経済・経営 / 法学 / 理工学 / 情報 / その他 |
| 前職経験月数 | 整数 | 前職での経験月数。新卒は0 |
| 前職職種 | カテゴリ | 前職の職種（6区分）。前職のない社員は欠損 |
| 採用経路 | カテゴリ | 直接応募 / 人材紹介 / 社員紹介 / インターン など（8区分） |
| 性別 | カテゴリ | 男性 / 女性 |
| 初期職種 | カテゴリ | 配属時の職種（営業・顧客対応 / IT・エンジニアリング など6区分） |
| 初期部署ID | 文字列（ID） | 配属時の部署ID |
| 初期勤務地 | カテゴリ | 東京 / 大阪 / 愛知 など（7区分） |
| 初期等級 | 順序カテゴリ | G1〜G5。数字が大きいほど上位 |
| 初期役割 | カテゴリ | メンバー / シニア / リード / マネージャー など（6区分） |
| 初任給_円 | 整数 | 入社時の月例給与（円） |
| 入社時メモ | テキスト | 経歴、人物所見、キャリア志向、勤務地・働き方などの文章 |
| 上司からのフィードバック | テキスト | 上司による業務行動・育成観点の所見 |
| 同僚からのフィードバック | テキスト | 同僚による協働・業務行動の所見 |
| 10年定着ラベル | 整数（0/1） | Trainのみ。1＝120か月時点で在籍（定着）、0＝離職 |

## 社員月次データ（employee_monthly_*.csv）

社員1名×1か月につき1行の、月ごとに変化する在籍・所属・勤務・評価の記録です。通常のTrainとTestは入社後0〜23か月、`employee_monthly_train_full.csv` は入社後0〜119か月を収録しています。

| 列名 | 型（推奨） | 説明 |
| --- | --- | --- |
| 社員ID | 文字列（ID） | 社員を識別するID。社員属性データとの結合キー |
| 年月 | 日付 | 対象月。CSVでは各月の1日を YYYY-MM-DD 形式で記録 |
| 経過月数 | 整数 | 入社月を0とした経過月数。通常版は0〜23、full版は0〜119 |
| 年齢 | 整数 | その月時点の年齢 |
| 月末在籍状態 | カテゴリ | 月末時点の状態（在籍 / 休職 / 退職） |
| 部署ID | 文字列（ID） | その月に所属する部署のID |
| 職種 | カテゴリ | その月の職種（6区分） |
| 役割 | カテゴリ | その月の役割（メンバー、シニア、リード、マネージャーなど） |
| 等級 | 順序カテゴリ | その月の等級。数字が大きいほど上位 |
| 上司ID | 文字列（ID） | その月の直属上司を識別するID |
| 勤務地 | カテゴリ | その月の勤務地（7区分） |
| 月例給与_円 | 整数 | その月の月例給与（円） |
| 360度評価_親和度 | 小数（欠損あり） | 対人関係の築きやすさに関する直近評価（1〜5、5が最高点） |
| 360度評価_信頼度 | 小数（欠損あり） | 周囲からの信頼に関する直近評価（1〜5、5が最高点） |
| 360度評価_主体度 | 小数（欠損あり） | 主体的な行動に関する直近評価（1〜5、5が最高点） |
| 360度評価_学習度 | 小数（欠損あり） | 学習・成長行動に関する直近評価（1〜5、5が最高点） |
| 360度評価_共有貢献度 | 小数（欠損あり） | 情報共有や周囲への貢献に関する直近評価（1〜5、5が最高点） |
| 360度評価更新フラグ | 整数（0/1） | その月に360度評価が更新された場合は1、更新がない場合は0 |
| 360度評価者数 | 整数（欠損あり） | 直近の360度評価に参加した評価者数 |
| 担当プロジェクト数 | 整数（欠損あり） | その月に担当したプロジェクト数 |
| 顧客満足度評価 | 小数（欠損あり） | 顧客満足度の評価値（1〜5、5が最高点） |
| 残業時間 | 小数 | その月の残業時間 |
| 有給取得日数 | 小数 | その月に取得した有給休暇の日数 |
| 欠勤日数 | 小数 | その月の欠勤日数 |
| 研修時間 | 小数 | その月に受講した社内研修などの時間 |
| 自己学習（詳細） | テキスト | 自己学習のテーマと時間。学習がない月は 受講なし |
| 上司との面談実施回数 | 整数 | その月に上司と面談した回数 |
| 情報共有件数 | 整数 | その月に記録された情報共有の件数 |
| 在宅勤務日数 | 整数 | その月の在宅勤務日数 |

**360度評価とは**：直属の上司だけでなく、同僚・部下・他部署の社員など、周囲の多様な関係者が多方向（360度）から1人の社員を評価する人事評価手法です。

## サンプルサブミッション（sample_submission.csv）

`sample_submission.csv` は投稿ファイルの形式を示すひな型です。`employee_persona_test.csv` と同じ 社員ID順で2,502行あり、初期値として全社員の予測確率に 0.5 が入っています。

| 列位置 | 型 | 説明 |
| --- | --- | --- |
| 1列目 | 文字列（ID） | 社員ID |
| 2列目 | 小数 | 10年定着確率。0以上1以下の確率 |

ファイルにヘッダー行はありません。
