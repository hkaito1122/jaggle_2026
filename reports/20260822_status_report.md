## 今セッションの主な出来事

2026-08-21〜22、`77_`の447列を起点に4つの検証を回した。うち2つはリークの発見と修正、2つは「検証をどこまで信じるか」という運用ルール自体の訂正だった。

### ① Target Encoding のリーク（78_/79_ → 80_/81_で修正）

部署Target EncodingをTrain全件でfitしてからouter KFoldを回すと、outer検証foldの情報がEncoding経由で漏れる。`build_features(train_id_subset)`でfold毎に再計算する形に修正し、以後84_まで踏襲。

### ② 特徴量選択のリーク（81_のTOP20PCT、史上最大級の反転）

「重要度上位20%を選ぶ」ステップをCVの外側で1回だけ行うと、選択自体が検証foldの情報を含んでしまう。局所val −0.016改善 → Public +0.006悪化という、振れ幅0.024の反転を引き起こした。

84_で選択をfold毎にネストし直したところ、改善は跡形もなく消えて悪化に転じ、「選択リーク」という原因診断が直接裏付けられた。

### ③ 分解能未満の局所val差は方向すら無意味（83_→84_TOP30PCTで確定）

KFold OOFの分解能は ±0.0043。83_の局所val「+0.0016悪化」はPublicでほぼ同着だった。さらに84_のTOP30PCTは局所val「+0.0022悪化」がPublicでは**−0.0020の明確な改善**に完全反転——同着どころか符号が逆だった。

> **運用ルールを修正**: 「検証の悪化は信頼できる」という数少ない拠り所にも分解能の下限が必要。分解能未満の構成は、局所valの結果を見ずにPublicで確認する。

### ④ 84_TOP30PCTが単層CatBoostの新記録に、そのままアンサンブルでも新記録

447列中134列にネスト選択で絞った構成がPublic 0.509500（77_比 −0.002048）。差分の45列を分析すると単一の「決定打」ではなく、360度評価の統計量ブロック（18/45列）と生の報酬・属性列（初任給・月例給与・性別・採用経路）が主体の分散した集合だった。

これを現最良ブレンドに重み15%で足しただけ（重み探索なし、事前登録1構成）で全体最良 0.496944 を更新。

## 次のアクション：GBDT以外のモデルで最良を狙う

**ユーザー方針**: スコアが即座に伸びなくても、GBDT系ではないモデルで最良を目指す。ここまでの特徴量エンジニアリングは54_系パイプラインに対して足がかりが薄くなってきており、次の一手を「モデル側」に移す判断は理にかなう。

### 非GBDT系モデルの現状

| モデル | 種別 | 状態 | 単体val |
|---|---|---|---|
| TabPFN v2（top150列） | 表形式基盤モデル（Transformer） | 採用・現最良に寄与 | 0.507569 |
| TabICL | 表形式基盤モデル | 弱い相方として一部使用 | 0.513460 |
| EBM | 加法モデル（boosted GAM） | 閉じた・TabPFNの劣化版 | 0.514536 |
| GP / SVM / MLP / LogReg / ExtraTrees | 古典ML（CPU） | 閉じた・混ぜる価値ゼロ | 0.535〜0.574 |
| GRU（月次系列） | RNN | 閉じた・絶対性能不足 | +0.136 |
| FT-Transformer / SAINT / TabNet / NODE | 深層表形式モデル | **未着手** | — |

### 提案

1. **TabPFN v2を84_TOP30PCTの134列に直接適用する。** TabPFNは列数が少ないほど強いという実績があり（441列→150列で単体val 0.0145改善）、134列という今回の新構成はまさにその好条件に当たる。既存のTabPFN(top150)とは特徴量ソースが異なるため、プールに対する追加の多様性も見込める。
2. **深層表形式アーキテクチャ（FT-Transformer / SAINT / TabNet）を初めて評価する。** CPU古典MLの動物園は71_で閉じ、AutoGluonのNN_TORCHも除外が正解だったが、これらは「浅い」モデル・シンプルなNNに限られる。Attentionベースの深層表形式モデルはこのプロジェクトでまだ一度も試していない、唯一残る非GBDTの未踏領域。
3. **期待値を揃える。** TabPFN単体でもCatBoostに対し互角止まりだった実績を踏まえると、深層表形式モデルが単体でGBDT系を上回る可能性は低い。目的はスコアの跳躍ではなく、私的LB分散最小化戦略に沿った「低相関・互角な強さのアンサンブル相方」を増やすことに置く。
