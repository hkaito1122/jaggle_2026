## 01 の要点

**最重要の発見（第3.1節）**

文献群が指摘する「コホート効果」を本データで点検したところ、特徴量設計の欠陥が見つかった。

- Train（入社 2011-04〜2014-03）と Test（2014-04〜2017-03）は**入社年で完全に分離**している
- にもかかわらず `入社年` は特徴量として渡されている
- 80%学習時にモデルが見る `入社年` は {2011, 2012, 2013} のみ。全件学習でも2014年は**60名だけ**
- **Testの2,502名は全員 `入社年` ≥ 2014**（うち2,493名は学習時に一度も現れない値）
- この欠陥は検証セット（2013年493名+2014年60名）にはほとんど現れず、**Publicにだけ現れる**

**検証済み（学習不要の診断）**

- 学習範囲内(2011-2013)の `入社年` は振れ幅 **3.2%pt、カイ二乗 p=0.345** で信号なし
- 「入社年≥2014」の学習側の証拠は **60名だけ**、定着率0.6500の95%CI [0.5245, 0.7614] は
  ≤2013の0.5628を含む（Fisher p=0.190）＝区別できない
- つまり「**信号が無く、かつ全Testが外挿域に落ちる**」列で、残す理由が無い

**対応**: [`src/41_hire_year_extrapolation.ipynb`](../src/41_hire_year_extrapolation.ipynb) を作成済み。
`X0`(全441列) と `X1`(−`入社年` の440列) を同一シードで学習し、**予測差として寄与を分離**する。
441列すべての外挿監査も同梱（同種の列が他にないかの自動チェック）。

**期待値は控えめに**: depth=4・強正則化なので **0.000〜0.003 程度**。
得点を伸ばす施策ではなく、設計上の不備を潰す位置づけ。

**文献から新規に実行する価値がある仮説は1つだけ**

- 部署 × 職種単位の**勤続賃金カーブの傾き**（小林2016の中核メカニズム）。
  ただし本データは24ヶ月しかなく、まずEDAで生の効果量を測ってから判断する。

**文献が支持した既存の設計**

- `初任給_等級内偏差` 等（JILPT2016「成果に見合った賃金」）
- ブロックL の交互作用エンコード（Kachi et al. 2018 と同型の部分集団効果）
- 産業・職業に相当する変数を重視していないこと（小林2016 で有意差なし）
- 検証セットの生存者補正（Works2023 のブランク分析と同じ選択バイアス構造）

**重要な留保**

本レビューの文献はほぼすべて**3年以内**の離職を扱っている。本コンペの目的変数は**10年定着**であり、
かつ3年内離職者は Test から構造的に排除されている（[test-set-is-survivor-filtered]）。
本プロジェクトが実測した予測ホライズン依存性を踏まえると、
**文献の知見をそのまま10年定着に持ち込むことはできない。**

## 検証レベルの表記

レポートでは文献ごとに一次資料の取得状況を明示している。
本文を読めていない文献については独自の要約を書かず、他文献による引用のみを記載している。

| 記号 | 意味 |
|---|---|
| ◎ | 本文（PDF/記事全文）を取得・精読した |
| ○ | 公式の概要ページまたは抄録を取得した。本文は未取得 |
| △ | 書誌情報のみ。本文・抄録とも未取得 |
